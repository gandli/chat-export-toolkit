**能力分级定义**：

| **L1** | 完整支持 | 适配器、标准化器、导出器全部实现并经过实际页面验证 |

| **L3** | 规划中 | 已列入路线图，等待实现 |

## 样本收集指南

对于未开始或骨架状态的平台，建议按以下步骤收集样本：

### 步骤 1：网络请求捕获

1. 打开平台网页版并登录
2. 打开浏览器开发者工具（F12）
3. 切换到 Network 标签
4. 开始一次新的对话或打开历史对话
5. 筛选 XHR/Fetch 请求
6. 查找包含对话内容的 API 响应

### 步骤 2：关键信息记录

对于每个关键 API 端点，记录：

- **请求 URL**（完整路径）
- **请求方法**（GET/POST）
- **请求头**（尤其是认证相关）
- **请求体**（如有）
- **响应结构**（完整 JSON）
- **触发时机**（页面加载/滚动/点击）

### 步骤 3：DOM 结构分析

1. 使用 Elements 标签查看对话区域 DOM
2. 记录消息容器的选择器
3. 记录消息气泡、头像、时间戳等元素的选择器
4. 注意懒加载和虚拟滚动行为

### 步骤 4：样本整理

将收集的信息整理为：
- API 端点文档
- 响应结构示例（脱敏）
- DOM 选择器清单
- 特殊行为说明（如流式响应、分页等）

## 风险与注意事项

### 技术风险

1. **API 变更** - 各平台可能随时调整 API 结构
2. **反爬措施** - 部分平台可能有速率限制或反自动化检测
3. **认证机制** - 某些平台可能使用复杂的认证流程
4. **CORS 限制** - 可能影响请求拦截

### 合规风险

1. **服务条款** - 需遵守各平台的使用条款
2. **数据隐私** - 仅处理用户本地数据，不上传外部
3. **版权限制** - 不复制平台内容，仅提供导出工具

### 维护成本

1. **多平台同步** - 每个平台都需要独立维护
2. **回归测试** - API 变更后需要重新验证
3. **用户支持** - 不同平台问题需要分别排查
